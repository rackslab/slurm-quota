== Name

slurm-quota-serve - HTTP JSON API for Slurm quota

== Synopsis

*slurm-quota-serve* [*-h*] [*--debug* | *-q* | *--quiet*] [*--version*] [*--host* <host>] [*--port* <port>] [*--idle-timeout* <seconds>] [*--conf-defs* <path>] [*--config* <path>] [*--dump-config*]

== Description

*slurm-quota-serve* runs an HTTP JSON service. It is designed to work with
systemd socket activation and is consumed by `slurm-quota stats` and
`slurm-quota-web`.

The command must run as the `slurm` system user.

== Options

*-h*, *--help*::
  Show help and exit.

*--debug*::
  Enable debug output.

*-q*, *--quiet*::
  Only print errors and warnings.

*--version*::
  Show program version and exit.

*--host* <host>::
  Bind host when not socket-activated (default: `127.0.0.1`).

*--port* <port>::
  Bind port when not socket-activated (default: `9911`).

*--idle-timeout* <seconds>::
  Exit after inactivity (default: `600`). `0` disables idle shutdown.

*--conf-defs* <path>::
  Path to YAML settings definition file (default: bundled `serve.yml`).

*--config* <path>::
  Path to site INI configuration file (default: `/etc/slurm-quota/serve.ini`).

*--dump-config*::
  Dump resolved configuration values and exit. Passwords are masked.

Notes:

- If systemd socket activation is active (`LISTEN_PID`/`LISTEN_FDS`), inherited FD 3 is used and `--host`/`--port` are ignored.
- The command exits with error if not run as the `slurm` system user.

== Environment

*LISTEN_PID*, *LISTEN_FDS*::
  Used to detect systemd socket activation.

*SLURM_QUOTA_SERVE_CONF_DEFS*::
  Override path to the YAML settings definition file.

*SLURM_QUOTA_SERVE_CONFIG*::
  Override path to the site INI configuration file.

== Examples

....
slurm-quota-serve --host 127.0.0.1 --port 9911 --idle-timeout 600
curl http://127.0.0.1:9911/health
TOKEN=$(sudo slurm-quota-token alice)
curl -H 'Authorization: Bearer '"$TOKEN" http://127.0.0.1:9911/stats
curl -H 'Authorization: Bearer '"$TOKEN" 'http://127.0.0.1:9911/stats?username=alice'
curl -H 'Authorization: Bearer '"$TOKEN" 'http://127.0.0.1:9911/stats?account=hpc'

slurm-quota-serve --dump-config

# With authentication.method=ldap in /etc/slurm-quota/serve.ini
curl -s -X POST http://127.0.0.1:9911/login \
  -H 'Content-Type: application/json' \
  -d '{"username":"alice","password":"secret"}'
curl -H 'Authorization: Bearer <token>' http://127.0.0.1:9911/stats
curl -H 'Authorization: Bearer <token>' http://127.0.0.1:9911/me
curl -H 'Authorization: Bearer <token>' http://127.0.0.1:9911/roles
curl -X PUT -H 'Authorization: Bearer <token>' http://127.0.0.1:9911/roles/managers/bob
....

== Files

`/var/lib/state/slurm-quota/slurm-quota.db`::
  SQLite database for quotas, consumed/preallocated counters, GPU factors, default settings, and API manager roles.

`/usr/share/slurm-quota/conf/serve.yml`::
  YAML settings definition for the HTTP service.

`/etc/slurm-quota/serve.ini`::
  Site configuration overrides (authentication, LDAP, JWT, authorization admins).

`/var/lib/slurm-quota/jwt.key`::
  Default path for the JWT signing key.

== Exit Status

*0*::
  Success.

*1*::
  Runtime/permission/operational error.
