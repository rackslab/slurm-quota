== Name

slurm-quota - manage Slurm CPU/GPU quota accounting, limits, and stats

== Synopsis

*slurm-quota* [*-h*] [*--debug* | *-q* | *--quiet*] [*--log-flags* <flag>]... [*--debug-flags* <flag>]... [*--version*] <command> [<args>...]

== Description

*slurm-quota* is a REST API client for the `slurm-quota-serve` HTTP service.
It manages CPU and GPU minute quotas for Slurm users and accounts, configures
quota and GPU charging settings, and displays consumption statistics.

== Global Options

*-h*, *--help*::
  Show help and exit.

*--debug*::
  Enable debug output.

*-q*, *--quiet*::
  Only print errors and warnings.

*--log-flags* <flag>::
  Component whose logs are enabled (repeatable; special value `ALL`). Default: `slurm_quota`.

*--debug-flags* <flag>::
  Component whose debug logs are enabled when *--debug* is used (repeatable; special value `ALL`). Default: `slurm_quota`.

*--version*::
  Show program version and exit.

== Commands

=== login

*slurm-quota login* [<username>] [*--save*]

Authenticate with LDAP and obtain a JWT from the HTTP service (`POST /login`).
Requires LDAP authentication enabled on `slurm-quota-serve`.

Options:

*<username>*::
  Optional LDAP username. Defaults to the current OS user when omitted.

*--save*::
  Save the token to `$XDG_CONFIG_HOME/slurm-quota/token` (default:
  `~/.config/slurm-quota/token`). Without this option, the token is printed to
  stdout.

Examples:

....
slurm-quota login
slurm-quota login bob
slurm-quota login --save
....

=== token

*slurm-quota token* [*--save*]

Show metadata about the current API authentication token (source, username,
expiration). The effective token is read from *SLURM_QUOTA_TOKEN* when set,
otherwise from `$XDG_CONFIG_HOME/slurm-quota/token`.

Options:

*--save*::
  Save the JWT from the *SLURM_QUOTA_TOKEN* environment variable to
  `$XDG_CONFIG_HOME/slurm-quota/token` for automatic use by other subcommands.

Examples:

....
slurm-quota token
export SLURM_QUOTA_TOKEN=$(sudo slurm-quota-token alice)
slurm-quota token --save
....

=== stats

*slurm-quota stats* [<username>] [*--user* <username>] [*--account* <account>] [*--all*] [*--hours*]

Display quota statistics (consumed, preallocated, quota, and status) for users
and/or accounts using the HTTP service (`/stats`).

Options:

*<username>*::
  Optional positional user selector.

*--user* <username>::
  User selector equivalent to positional `<username>`.

*--account* <account>::
  Account selector.

*--all*::
  Show all users/accounts (no username filter).

*--hours*::
  Display values in hours instead of minutes.

Notes:

- Positional `<username>` and `--user` are mutually exclusive.
- User selection (`<username>` or `--user`) and `--account` are mutually exclusive.
- If no selector is provided, the current OS user is used.

Examples:

....
slurm-quota stats
slurm-quota stats alice
slurm-quota stats --account hpc
slurm-quota stats --all --hours
....

=== role

*slurm-quota role* *show* | *list* | *grant* <operator|manager> <username> | *revoke* <operator|manager> <username> | *managers* <username> *list* | *managers* <username> *add* <account> | *managers* <username> *remove* <account>

Show or manage REST API user roles. Requires a saved JWT token or
`SLURM_QUOTA_TOKEN`.

Subcommands:

*show*::
  Display the current caller username and role.

*list*::
  List all users with their role (admin only).

*grant* <operator|manager> <username>::
  Grant operator or manager role to a user (admin only).

*revoke* <operator|manager> <username>::
  Revoke operator or manager role from a user (admin only).

*managers* <username> *list*::
  List accounts assigned to a manager (admin only).

*managers* <username> *add* <account>::
  Assign an account to a manager (admin only).

*managers* <username> *remove* <account>::
  Remove an account from a manager (admin only).

Examples:

....
slurm-quota role show
slurm-quota role list
slurm-quota role grant operator bob
slurm-quota role grant manager bob
slurm-quota role revoke operator bob
slurm-quota role managers bob list
slurm-quota role managers bob add hpc
....

=== adjust

*slurm-quota adjust* (*--user* <username> | *--account* <account>) (*--cpu* | *--gpu*) (*--minutes* <signed_int> | *--hours* <signed_int>)

Adjust consumed CPU/GPU time for one user or one account.
Requires a saved JWT token or `SLURM_QUOTA_TOKEN`, and operator or admin role.

Options:

*--user* <username>::
  Target user.

*--account* <account>::
  Target account.

*--cpu*::
  Adjust consumed CPU minutes.

*--gpu*::
  Adjust consumed GPU minutes.

*--minutes* <signed_int>::
  Signed delta in minutes, must include `+` or `-` (example: `+30`, `-120`).

*--hours* <signed_int>::
  Signed delta in hours, must include `+` or `-`. Converted to minutes internally.

Notes:

- Negative adjustments are clamped at zero (consumed time never becomes negative).

Examples:

....
slurm-quota adjust --user alice --cpu --minutes=+30
slurm-quota adjust --account projX --gpu --hours=-1
....

=== user-quota

*slurm-quota user-quota* <username> <quota_minutes>

Set user CPU quota in minutes (`-1` means unlimited). Requires a saved JWT
token or `SLURM_QUOTA_TOKEN`, and operator or admin role.

Example:

....
slurm-quota user-quota alice 50000
....

=== account-quota

*slurm-quota account-quota* <account> <quota_minutes>

Set account CPU quota in minutes (`-1` means unlimited). Requires a saved JWT
token or `SLURM_QUOTA_TOKEN`, and operator or admin role.

Example:

....
slurm-quota account-quota projX 200000
....

=== user-gpu-quota

*slurm-quota user-gpu-quota* <username> <quota_gpu_minutes>

Set user GPU quota in minutes (`-1` means unlimited). Requires a saved JWT
token or `SLURM_QUOTA_TOKEN`, and operator or admin role.

Example:

....
slurm-quota user-gpu-quota alice 10000
....

=== account-gpu-quota

*slurm-quota account-gpu-quota* <account> <quota_gpu_minutes>

Set account GPU quota in minutes (`-1` means unlimited). Requires a saved JWT
token or `SLURM_QUOTA_TOKEN`, and operator or admin role.

Example:

....
slurm-quota account-gpu-quota projX 50000
....

=== gpu-factors

*slurm-quota gpu-factors*

Show configured GPU charging factors. Requires a saved API token or
`SLURM_QUOTA_TOKEN` (operator or admin role).

=== set-gpu-factor

*slurm-quota set-gpu-factor* <gpu_type> <factor>

Set GPU charging factor for a GPU type (`default` is accepted as fallback type). Argument _factor_ must be a positive float (> 0).
Requires a saved API token or `SLURM_QUOTA_TOKEN` (operator or admin role).

Example:

....
slurm-quota set-gpu-factor h100 0.5
....

=== default-quotas

*slurm-quota default-quotas*

Show default quotas used for newly auto-created users/accounts.
Requires a saved API token or `SLURM_QUOTA_TOKEN` (operator or admin role).


=== set-default-quotas

*slurm-quota set-default-quotas* [*--user-cpu* <minutes>] [*--user-gpu* <minutes>] [*--account-cpu* <minutes>] [*--account-gpu* <minutes>]

Set one or more default quotas for newly auto-created users/accounts.
At least one option is required at runtime. Argument _minutes_ must be a positive integer or `-1` means unlimited.
Requires a saved API token or `SLURM_QUOTA_TOKEN` (operator or admin role).

Example:

....
slurm-quota set-default-quotas --user-cpu 50000 --account-cpu 200000
....

== Environment

*SLURM_QUOTA_URL*::
  Base URL used by CLI subcommands that query the HTTP API (`stats`, `login`,
  quota management, and related commands).
  Default: `http://127.0.0.1:9911/`

*SLURM_QUOTA_CA_CERT*::
  Path to a CA certificate file used to verify the REST API TLS certificate when
  `SLURM_QUOTA_URL` uses `https://` and the certificate is not trusted by the
  system default store.

*SLURM_QUOTA_TOKEN*::
  JWT for HTTP API authentication. When set, takes precedence over the token
  file saved by `login --save` or `token --save`.

*XDG_CONFIG_HOME*::
  Base directory for user-specific configuration. The token saved by `login` is
  stored in `$XDG_CONFIG_HOME/slurm-quota/token` (default:
  `~/.config/slurm-quota/token`).

*NO_COLOR*::
  If set, disables colored status bars in `stats` output.

== Files

`$XDG_CONFIG_HOME/slurm-quota/token`::
  JWT saved by `login --save` or `token --save` for HTTP API authentication
  (default: `~/.config/slurm-quota/token`).

== Exit Status

*0*::
  Success.

*1*::
  Runtime/permission/operational error, or no subcommand provided.

*2*::
  Command-line parsing error (for example, mutually exclusive options used together).
