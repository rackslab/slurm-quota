== Name

slurm-quota-web - HTTP server for Slurm quota statistics web dashboard

== Synopsis

*slurm-quota-web*

== Description

*slurm-quota-web* starts a HTTP server that renders Slurm quota and consumption
statistics in HTML web dashboard.

The dashboard consumes the existing `slurm-quota` HTTP API exposed by
`slurm-quota-serve`. A valid JWT is always required to query the API.

When `authentication.method=ldap`, the dashboard presents a login page. Users
authenticate with their LDAP credentials; the application obtains a JWT from
`POST /login` and stores it in a signed, HttpOnly session cookie. Each browser
session is independent.

Alternatively, set *SLURM_QUOTA_TOKEN* in the web server environment to
authenticate API calls with a service token (no per-user login page).

== Environment

*SLURM_QUOTA_URL*::
  Base URL of the slurm-quota HTTP API queried by the dashboard.
  Default: `http://127.0.0.1:9911/`

*SLURM_QUOTA_TOKEN*::
  JWT for HTTP API authentication. When set, the dashboard uses this token for
  `/stats` requests and skips the login page.

*SLURM_QUOTA_WEB_SESSION_KEY_FILE*::
  Path to a file containing the session signing key. See *Session key*
  section for details.

*SLURM_QUOTA_WEB_SESSION_KEY*::
  Session signing key passed directly in the environment. Alternative to
  `SLURM_QUOTA_WEB_SESSION_KEY_FILE`. See *Session key* section for details.

*SLURM_QUOTA_WEB_SECURE_COOKIES*::
  When set to `1`, session cookies are marked `Secure`. Recommended when the
  dashboard is served over HTTPS.

*SLURM_QUOTA_WEB_SESSION_DAYS*::
  Session cookie lifetime in days. Default: `1` (aligned with default JWT
  duration on the REST API).

*SLURM_QUOTA_WEB_ASSETS_DIR*::
  Optional directory containing `templates/` and `static/` subdirectories.
  If unset, the app tries the repo-root `web/` directory (development),
  then the pip-installed data directory (`{prefix}/slurm-quota/web/`),
  then `/usr/share/slurm-quota/web`.

*SLURM_QUOTA_WEB_HOST*::
  Bind host used by standalone mode.
  Default: `127.0.0.1`

*SLURM_QUOTA_WEB_PORT*::
  Bind port used by standalone mode.
  Default: `5000`

*SLURM_QUOTA_WEB_DEBUG*::
  If set to `1`, enables Flask debug mode in standalone execution.

== Session key

When `authentication.method=ldap` and users sign in through the browser, the
dashboard stores each user's API JWT in a signed session cookie. A server-side
session key is required to sign those cookies so they cannot be forged or
altered by clients. When only *SLURM_QUOTA_TOKEN* is used, no session key is
needed.

The key can be provided in two ways:

*SLURM_QUOTA_WEB_SESSION_KEY*::
  Session key value passed directly in the environment.

*SLURM_QUOTA_WEB_SESSION_KEY_FILE*::
  Path to a file containing the session key. A single trailing newline is ignored.
  Prefer this method in production so the key is not embedded in process listings
  or web server configuration.

If both variables are set, *SLURM_QUOTA_WEB_SESSION_KEY* takes precedence over
*SLURM_QUOTA_WEB_SESSION_KEY_FILE*.

To generate a new key:

....
openssl rand -hex 32
....

== Examples

....
# default standalone launch
slurm-quota-web

# custom API endpoint
SLURM_QUOTA_URL=http://controller:9911/ slurm-quota-web

# with REST API LDAP authentication enabled
SLURM_QUOTA_WEB_SESSION_KEY_FILE=/etc/slurm-quota/web-session.key slurm-quota-web

# custom bind host/port
SLURM_QUOTA_WEB_HOST=0.0.0.0 SLURM_QUOTA_WEB_PORT=8080 slurm-quota-web
....

== Exit Status

*0*::
  Server exited cleanly.

*1*::
  Runtime failure.
